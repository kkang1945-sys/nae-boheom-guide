# 개인정보 보호와 보안

보험 PDF, 경제정보와 분석 결과는 민감한 개인 데이터로 취급한다.

## 기본 원칙

- 목적에 필요한 최소 데이터만 수집한다.
- 로컬 처리·보관을 우선한다.
- 외부 OCR/AI 전송은 전송 범위·보관·삭제 조건을 검토하고 사용자가 동의하기 전 금지한다.
- 로그와 오류 메시지에 PDF 원문, 성명, 증권번호, 경제정보를 남기지 않는다.
- 개발·테스트에는 합성 또는 승인된 익명화 데이터만 사용한다.
- 실제 PDF를 저장소에 커밋하지 않는다.

## 업로드와 저장

- PDF 형식, 크기, 페이지 수를 검증한다.
- 파일명은 표시용이며 저장 경로로 신뢰하지 않는다.
- 무작위 문서 ID와 해시를 사용한다.
- 경로 조작, 실행 파일 위장, 악성 PDF와 리소스 고갈을 고려한다.
- 암호화와 키 관리는 기술 스택 확정 후 결정 기록에 추가한다.

## 외부 처리 도입 조건

제공자·처리 지역, 전송 페이지와 마스킹, 모델 학습 사용 여부, 보존기간·삭제, 실패 재전송, 비용·한도, 로컬 대안을 문서화한다. 승인 전 실제 원문을 외부에 보내지 않는다.

## 삭제 의미

1. 원본 PDF 삭제: 원본과 페이지 렌더링·OCR 중간 파일 삭제. 추출·분석 보존 여부를 명시한다.
2. 전체 데이터 삭제: 원본, 중간 파일, 추출값, 사용자 수정, 경제정보, 분석 결과, 임시 내보내기 삭제.

삭제 전에 정확한 대상을 정하고 부분 실패를 표시한다. 완료 시각과 범위만 민감정보 없는 감사 이벤트로 남긴다. 백업을 도입하면 복구 가능 기간과 최종 소거 시점을 공개한다.

## 화면과 내보내기

- 민감 필드는 기본 마스킹하고 원문은 명시적 동작으로 연다.
- 2026-09-09부터 원문 열기 화면도 저장 원본을 직접 제공하지 않고, 주민·연락처·이메일·라벨형 이름·식별번호·주소를 검은 영역으로 가린 메모리 PNG만 표시한다.
- 직접 읽은 글자와 로컬 OCR 글자는 화면에서 마스킹한다. 한 페이지에서 식별된 값은 문서의 다른 페이지에 반복되어도 함께 가린다.
- 원본·OCR·추출·감사값은 로컬 검산을 위해 보존하고, PDF/CSV 내보내기에는 마스킹된 대상자·문서명·원문 유래 문구만 포함한다.
- 내보내기에 포함될 개인정보를 사전에 보여주며 임시 파일을 정리한다.
- 브라우저 저장소, 클립보드, 다운로드 폴더의 잔존 위험을 안내한다.

- [ ] 다른 분석 건 데이터 접근 차단
- [x] 로그·오류에 민감정보 없음
- [ ] 실패·취소·재시도 후 임시 파일 정리
- [ ] 원본 삭제·전체 삭제 대상과 잔존 파일 검증
- [x] 승인되지 않은 외부 데이터 전송 없음
- [x] 내보내기 임시 파일 수명 검증

2026-09-09 실제 문서 점검에서 관련 HTML 14개와 PNG 미리보기 7개가 모두 `200`, `no-store`로 응답했고 자동 식별한 민감값의 HTML 재노출은 0건이었다. PNG는 문서 전체 반복값까지 좌표로 가렸으며 원본과 앱 관리 사본의 SHA-256은 처리 전후 동일했다. 이는 알려진 형식에 대한 기술 검증이며 사람의 육안 검수를 대신하지 않는다.

공개 서비스 전에는 법률 검토, 개인정보 처리방침, 인증·권한, 키 운영, 침해 대응, 백업·파기와 공급업체 검토가 추가로 필요하다. 이 문서는 법률 자문이 아니다.

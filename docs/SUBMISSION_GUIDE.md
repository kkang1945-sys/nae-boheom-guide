# 작품 제출·시연 가이드

## 한 문장 소개

`내보험 사용설명서`는 보험을 추천하는 앱이 아니라, 사용자의 실제 보험증권을 로컬에서 읽고 생활비 중심의 자금공백과 원문 근거를 보여주는 앱이다.

## 문제와 차별점

기존 보험 비교는 담보 개수나 또래 평균을 중심으로 보여주는 경우가 많다. 이 앱은 월 필수생활비, 비상자금, 부채, 부양가족처럼 사용자가 직접 입력한 경제상황을 기준으로 계산한다.

핵심 차별점은 다음 세 가지다.

1. 보험증권의 추출 후보와 사용자 확정값을 분리하고 원문 페이지로 연결한다.
2. 진단비·사망·입원·실손처럼 지급 기준이 다른 담보를 하나의 금액으로 잘못 합산하지 않는다.
3. 부족액만 보여주지 않고 출처, 가정, 계산식, 제외 항목과 한계를 함께 공개한다.

## 3분 시연 순서

1. 첫 화면에서 기존 보험증권 두 개를 함께 연다.
2. 증권 카드에서 보험별 주요 보장내용·보장금액 5개를 짧게 보여준다.
3. `내 보장 계산하기`를 눌러 월 필수생활비, 비상자금, 남은 대출, 부양가족을 입력한다.
4. 결과에서 진단비의 생활비 유지 개월 수와 상해사망 증권 기준금액을 보여준다.
5. `왜 이렇게 계산했나요?`를 열어 계산식과 사용한 자금을 확인한다.
6. 결과 하단에서 보험별 `이 보험증권 자세히 보기`를 열어 쉬운 설명과 증권 지급조건을 보여준다.
7. `입원·통원·수술 보장` 중 하나를 눌러 보험별 금액과 증권 원문을 보여준다.

기술적인 추출 검산·재추출·수정·삭제 기능은 보험증권 상세의 `고급 관리` 안에 있으며 기본 시연에서는 열지 않는다.

## 시연 입력 예시

- 월 필수생활비: 300만원
- 비상자금: 300만원
- 남은 대출: 0원
- 부양가족: 1명

이 입력에서는 확인된 진단비와 비상자금을 합쳐 월 필수생활비를 몇 개월 유지할 수 있는지 보여준다. 입원·통원·수술은 지급 방식이 달라 하나의 현금 계산으로 합치지 않고, 별도 화면에서 보험증권에 적힌 금액과 지급조건을 보험별로 보여준다.

### 고정 시연 확인 항목

- 첫 결론 문장에 계산된 질병명과 생활비 유지 기간이 표시된다.
- 같은 유지 기간의 질병 결과는 카드 하나로 묶이고 `질병별 금액 보기`에서 세부 금액을 확인한다.
- 상단 요약은 생활비 유지 기간, 확인한 보험증권 수, 계산한 질병 상황 수만 표시한다.
- 교보 수술비는 1종 20만원·2종 50만원·3종 100만원으로 나누어 표시한다.
- 추출 원문은 기본으로 닫혀 있고, 보험증권 이미지 원문으로 이동할 수 있다.

## 심사위원에게 설명할 안전장치

- 실손형과 정액형을 합산하지 않는다.
- 서로 다른 질병 진단비를 하나의 확정 보험금으로 합치지 않는다.
- 미확정 추출값은 계산에 사용하지 않는다.
- 보험금 지급 가능성을 확정하지 않는다.
- 정부 통계를 개인별 민간보험 권장 가입금액으로 표현하지 않는다.
- 특정 상품, 보험회사, 가입·해지 행동을 추천하지 않는다.
- 보험증권과 개인정보를 외부 생성형 AI로 보내지 않는다.

## 현재 한계

- 보험회사마다 다른 표 구조와 약관 의미를 모두 자동 확정할 수 없다.
- OCR 담보와 복수 단계형 금액은 `증권에서 읽은 내용`으로 출처를 구분하고 원문을 함께 제공한다. 사용자 확정 전에는 계산용 확정 보험금으로 합산하지 않는다.
- 입원 일당은 실제 입원일수, 면책일수와 지급한도를 확인하기 전에는 계산하지 않는다.
- 실손보험은 실제 발생 의료비와 약관상 자기부담이 필요하므로 가입금액처럼 생활비에서 차감하지 않는다.
- 현재 제출 버전은 개인 PC에서 실행하는 로컬 앱이며 공개 서비스용 인증·암호화·사용자 분리는 포함하지 않는다.

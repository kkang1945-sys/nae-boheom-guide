## 상태 판별의 한계

- `text_ready`: PDF 글자를 읽음. 담보 추출·정확도·완전성 확인 완료를 의미하지 않음.
- `needs_ocr`: 글자가 없거나 대체 문자·기호만 있음. 빈 페이지와 스캔을 확정적으로 구별하지 않음.
- `mixed_review`: 텍스트와 이미지가 함께 있음. 로고도 포함될 수 있으므로 스캔으로 단정하지 않고 누락 확인을 요청.
- 좌표는 PyMuPDF의 회전 전 좌표이다. 렌더링은 문서 회전을 반영한다. 추후 하이라이트는 회전 변환 필요.
- 당시 OCR은 실행하지 않았다. 2026-09-04에는 7쪽 로컬 OCR을 완료했지만 수치 신뢰도나 보험회사를 추측하지 않으며 담보 후보는 사용자 확인 전이다.
- 렌더링은 메모리 내 PNG로 제공하며 원본 PDF의 스크립트·외부 링크를 웹페이지에 직접 제공하지 않는다.

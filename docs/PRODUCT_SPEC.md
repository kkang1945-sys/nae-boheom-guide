# 제품 명세

## 제품 정의

사용자가 가진 보험을 쉬운 말로 이해하고, 다른 사람과 비교하지 않은 채 자신의 경제상황으로 위험별 자금공백을 계산하며, 모든 판단 근거를 검증할 수 있게 하는 개인용 보험 분석 도구다.

사용자가 해결하려는 실제 문제:

- 현재 가입한 보험이 무엇을 보장하는지 알기 어렵다.
- 기존 보험 분석 서비스는 부족하다는 결과 뒤에 보험·앱 가입을 유도하는 경우가 있다.
- 사용자는 판매 권유 없이 자신의 보장 내용, 부족한 위험과 추정 금액, 중복 가능성과 비용 검토 대상을 알고 싶다.
- 결과는 신뢰할 수 있는 정부·공공기관 자료와 개인 경제정보를 구분해 근거를 보여줘야 한다.

핵심 약속:

1. 이해: 여러 보험 PDF에서 무엇을 얼마 동안 얼마나 보장하는지 구조화하고 쉽게 설명한다.
2. 진단: 생활비·소득공백·자산·부채·가족 상황으로 자금공백을 계산한다.
3. 보완 안내: 상품이 아니라 위험 종류와 추정 공백만 보여주고 보험 외 대비수단도 알린다.
4. 정리: 같은 위험을 여러 번 보장하거나 유지 목적을 다시 살펴볼 담보를 찾되 해지·감액을 단정하지 않는다.

## 6주 성공 조건

공개 서비스가 아니라 사용자 본인의 실제 보험 PDF 여러 개에서 아래 흐름이 작동해야 한다.

```text
업로드 → 추출·자동 검산 → 표 요약·예외 확인 → 조건 검토 → 담보 통합 → 경제정보 입력
→ 자금공백 분석 → 근거 확인 → 저장 → 재분석 → 삭제
```

## 기능 요구사항

### PDF와 추출

- PDF 여러 개 업로드, 파일별 처리 상태·실패 이유, 원본 삭제
- 지원되는 4열·6열 담보 표를 분리해 읽고, 사용자 확인값이 없는 문서만 최신 규칙으로 안전하게 다시 추출
- 텍스트형·스캔형 PDF 처리
- 보험회사, 상품명, 주계약/특약, 원문 담보명, 가입금액과 단위, 보험기간, 납입기간, 갱신 여부, 지급 방식 추출
- 모든 추출값에 문서·페이지·원문 위치, 신뢰도, 확인 상태 연결
- 모르는 값은 `미확인`으로 남기고 추측하지 않음
- 원문·OCR·추출값은 감사용으로 보존하되 화면·PNG 미리보기·PDF/CSV 내보내기에서는 개인정보와 문서 전체 반복 식별값을 마스킹

### 확인·표준화·통합

- 업로드 후 앱이 독립 읽기·금액·기간·개수 검산을 먼저 수행하고, 통과한 표는 요약으로 진행한다. 사용자에게 전수 확인을 요구하지 않고 불일치·추가 자료가 필요한 예외를 제시한다. 사용자는 원문을 보고 선택적으로 수정·확정할 수 있다.
- 원본 추출값·자동 검산 기록·사용자 확정값을 별도 보존한다. 자동 검산 통과를 사람이 확인한 것으로 기록하지 않는다.
- 15개 표준 담보 연결: 실손의료비, 일반암, 유사암, 뇌혈관질환, 뇌졸중, 허혈성심장질환, 급성심근경색, 질병수술, 상해수술, 입원, 후유장해, 간병, 치매, 질병사망, 상해사망
- 진단·수술·입원·사망·장해·간병, 정액·실손, 1회·반복 지급 구분
- 안전한 경우만 합산하고 범위·면책·감액·갱신 차이 표시
- 표준 담보의 일반 설명과 계약의 구체 조건을 구분

### 분석 직전 검산 관문

추출 직후 표 읽기 검산과 조건 구조화 이후 분석 직전 검산을 분리한다. 두 관문은 테스트 완료 상태이며, 실제 보험에서는 미확인 핵심값이나 조건 범위가 남으면 차단 이유를 표시한다.

- 원문 표의 담보 수와 저장된 후보 수 비교
- 원문 금액·단위와 정규화한 원 단위 금액 재계산
- 보험기간과 납입기간 혼동, 갱신 여부, 주계약·특약 재검사
- 실손·정액형, 최초 1회·반복 지급 재검사
- 같은 문서·담보의 중복 등록과 누락 검사
- 합산 대상마다 허용 조건과 제외 이유 재평가
- 핵심값의 원문 위치와 검증 범위·자동 검산 또는 사용자 확인 근거 존재 확인

치명 오류나 검증되지 않은 핵심값이 하나라도 있으면 분석을 시작하지 않고 `검산 실패` 또는 `확인 필요`로 표시한다. 검산 결과에는 통과·경고·차단 항목과 이유를 보여준다.

### 경제정보와 분석

- 한 번의 분석은 대상자 한 명을 기준으로 한다. 여러 보험증권을 같은 대상자에게 연결할 수 있지만 가족 전체를 하나의 평균값으로 계산하지 않는다.
- 대상자의 관계, 생애단계, 경제적 역할과 성별·임신·출산 관련 담보 검토 범위를 별도로 확인한다. 성별·연령별 평균을 개인의 권장 보험금으로 사용하지 않는다.
- 아동은 본인 소득대체 대신 보호자 소득 감소·돌봄비가 준비되어야 계산하고, 은퇴·고령기는 근로소득 대신 연금 등 지속소득·돌봄비가 준비되어야 계산한다. 정보가 없으면 판단을 보류한다.
- 월 필수생활비, 월 세후소득, 소득중단 대비기간, 사용 가능한 비상자금, 유급휴가·회사 지원, 대출잔액, 부양가족, 가족 월 필수생활비, 가족생활 유지 희망기간, 즉시 금융자산, 위험 대비에 사용할 자금 범위 입력
- 아동은 보호자 월 소득 감소와 월 추가 돌봄비, 노년·은퇴기는 분석에 사용할 월 연금·지속소득과 월 의료·돌봄 본인부담을 별도 입력한다. 빈칸은 0원으로 취급하지 않으며 공식 제도 금액을 자동 추정하지 않는다.
- 중대질환 생활자금, 의료비, 사망·부채, 후유장해·간병·치매 장기 위험을 분리
- 제출용 기본 모의계산은 월 필수생활비·비상자금·남은 대출·부양가족의 네 항목만 받는다. 입원·휴직 기간, 유지소득, 추가비용, 회사 지원을 받는 상세 입원 생활자금 계산은 기본 흐름에 노출하지 않는다.
- 입원·통원·수술은 계산 가능 여부와 별개로 보험증권에 적힌 담보명·금액·복수 등급·지급조건을 보험별로 보여준다. 미확정 추출값은 `증권에서 읽은 내용`으로 출처를 표시하고 원문으로 연결하되, 실제 지급액 또는 합산 보험금으로 확정하지 않는다.
- 3·6·12개월 및 사용자 선택 시나리오
- `자금공백 없음`, `일부 자금공백`, `큰 자금공백`, `정보 부족으로 판단 보류` 표시
- 입력이나 확정 보험정보가 바뀌면 이전 결과를 보존한 새 버전으로 재분석

### 설명 가능한 결과

모든 주요 숫자에 보험계약 원문, 사용자 입력, 기준일이 있는 공식 근거, 앱 가정, 계산식, 제외 항목, 불확실성과 분석 한계를 제공한다. 사용자 수정값을 표시하고 결과에서 PDF 원문 페이지로 이동할 수 있어야 한다.

제출용 기본 화면은 계산 결론 한 문장과 생활비 유지 기간·확인한 보험증권 수·계산한 질병 상황 수를 먼저 보여준다. 같은 구조의 질병 결과는 카드 하나로 묶고 질병별 금액과 계산 근거는 펼쳐본다. OCR 지급조건과 검산·재추출·수정 기능은 기본 설명과 분리해 접어 두며, 쉬운 설명과 증권 이미지 원문 이동을 우선한다.

첫 화면은 `우선 검토 순위 → 부족해 보이는 보장 → 필요한 자금 → 현재 확인된 보험금 → 검토 필요 규모` 순서의 짧은 카드로 표시한다. 보장의 쉬운 설명을 함께 제공하고 계산식·기간별 비교·원문·지급조건은 펼쳐보기로 제공한다. `검토 필요 규모`는 사용자의 경제정보로 계산한 자금공백이며 특정 상품의 가입금액 추천으로 표현하지 않는다.

정부·공공기관 자료가 모든 사람에게 필요한 민간보험 가입금액을 정해주는 것은 아니다. 공식 자료는 공적보장 범위, 제도 적용 조건, 통계와 비용 근거를 설명하는 데 사용한다. 개인별 부족 금액은 해당 공식 자료와 사용자 생활비·소득공백·자산·부채를 사용한 앱 분석 결과로 명확히 구분한다.

사망 결과는 부족액뿐 아니라 확인된 사망보험금으로 가족생활비를 몇 개월 충당할 수 있는지 보여준다. 부채 상환 전·후를 분리하고, 사용자의 실제 가족생활비와 사망 후 남는 가구원 수에 해당하는 생계급여 최저보장수준을 나란히 표시한다. 공적 기준은 최소 참고선이며 평균 지출 또는 가입 권장액으로 표현하지 않는다.

실제 정보를 저장하지 않고 조건을 바꿔볼 수 있는 모의계산을 제공한다. 모의계산은 PDF 한 개와 사용자가 입력한 경제조건을 요청 중에만 사용하고 대상자·경제정보·결과 스냅샷을 만들지 않는다. 사망보장은 계산 완료, 미확정 후보, 업로드한 증권에서 찾지 못함을 구분하며 후보 가입금액은 확정보험금처럼 차감하지 않는다. 보험금 확정 전에도 개인 입력으로 계산되는 가족 필요자금은 별도로 보여주되 보험 가입 권장액으로 표현하지 않는다.

현재 생활자금 계산과 기준이 다른 입원·통원·수술 보장은 결과 하단의 별도 버튼에서 보험별 증권 표기와 원문을 확인한다. 찾지 못하거나 계산하지 않은 영역을 부족, 불필요 또는 가입 필요로 표현하지 않는다.

심평원 질병정보서비스의 입원·외래별 통계와 성별·연령별 통계는 별도 의료이용 참고정보로 제공한다. 질병코드와 조회 연도만 외부 API에 전송하고 보험증권·이름·경제정보는 전송하지 않는다. 공개 응답은 호출량 절감을 위해 로컬에 7일간 캐시하되 서비스 키는 파일·DB·화면·로그에 남기지 않는다. 통계값은 치료기간·휴직기간·소득중단 기간 또는 민간보험 필요액으로 자동 변환하지 않는다.

2026-09-08 기준 공적제도 확인 자료는 국민건강보험공단의 본인부담상한제, 본인일부부담금 산정특례, 재난적의료비 지원 기준, 노인장기요양보험 급여 안내다. 앱은 확인일과 공식 URL을 표시하며 제도 금액을 예상하거나 자금공백에서 자동 차감하지 않는다. 개인별 적용 여부는 공단의 현재 기준으로 직접 확인한다.

### 중복·축소 검토

- 동일 위험·급부·범위·기간·지급 조건의 정액 담보는 중복 가능성을 표시한다.
- 실손형은 가입금액을 합산하지 않고 실제 보상 구조가 중복 제한을 받는지 설명한다.
- 범위가 다른 담보는 중복으로 단정하지 않고 포함관계와 차이를 보여준다.
- `줄여야 한다`, `해지해야 한다`, `과잉보험이다`라고 단정하지 않는다.
- 사용자가 유지 목적, 보험료 부담, 해지 불이익과 재가입 가능성을 확인하도록 `유지 목적 검토 대상`으로 표시한다.
- 축소나 해지 행동을 권하기 전에 보험료, 납입기간, 해지환급·재가입 불이익 등 판단에 필요한 정보가 부족하면 판단을 보류한다.

### 저장과 삭제

- 결과 저장·다시 열기·재분석·내보내기
- 원본 PDF 삭제와 전체 데이터 삭제를 구분
- 삭제 범위와 성공·실패를 명확히 표시

## 핵심 화면

시작, 개인정보 안내, PDF 업로드, 분석 진행, 추출 확인·수정, 보험 통합, 경제정보 입력, 위험별 결과, 판단근거·원문, 저장 결과·재분석, 내보내기, 삭제.

## 비기능 요구사항

- 정확성: 금액 단위·기간·지급 유형을 검증하고 불확실한 값은 계산하지 않는다.
- 추적성: 결과에서 입력과 원문까지 이동한다.
- 재현성: 입력 스냅샷과 규칙 버전으로 결과를 재현한다.
- 개인정보: 최소 수집·전송·보관, 민감정보 로그 금지, 명시적 삭제.
- 복구성: 실패가 확인된 데이터와 원본을 손상시키지 않는다.
- 모바일: 작은 화면에서도 표, 원문 확인과 수정이 가능해야 한다.

## 제외 범위

보험 판매·가입·보험료 비교·설계사 연결, 특정 보험사·상품 추천·순위, 평균 기반 핵심 판정, 보험금 지급의 확정 판단, 사진(JPG/PNG) 직접 업로드, 6주 내 불특정 다수 공개 운영.

## 문구 원칙

권장: “현재 입력과 6개월 시나리오를 기준으로 약 500만원의 자금공백이 추정됩니다.”

금지: “암보험 500만원을 추가 가입해야 합니다.”, “보험금이 지급됩니다.”, “평균보다 부족합니다.”

이 명세는 `insurance_app_full_conversation.md`와 사용자의 최신 6주 목표를 반영한다. 충돌 시 사용자의 최신 명시 요청과 `AGENTS.md`의 제품 원칙을 따른다.

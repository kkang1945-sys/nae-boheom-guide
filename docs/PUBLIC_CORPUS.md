# 공개 보험 문서 기준 말뭉치

## 목적과 범위

이 프로젝트는 현재 별도 신경망을 재학습하지 않는다. 여기서 공개 자료를 “학습”한다는 말은 공식 문서에서 담보명과 조건 표현을 수집해 현재의 로컬 추출·분류 규칙을 평가하고, 확인된 예외만 규칙과 회귀 테스트에 반영한다는 뜻이다.

공개 상품요약서와 약관은 담보 용어, 면책·감액·대기기간·횟수 제한 문구를 점검하는 자료다. 개인별 가입금액이 표시된 보험증권의 표 구조를 대신하지 않으므로, 실제 증권 정확도는 사용자가 제공한 문서로 별도 검증한다.

## 자료 관리 원칙

- 추적 가능한 출처 명세는 `corpus/public_sources.json`에 둔다.
- 내려받은 원본과 생성 보고서는 `data/public_corpus/`에 두며 Git 추적과 앱의 개인 문서 DB에서 제외한다.
- 모든 직접 다운로드 원본은 SHA-256으로 고정한다. 출처 파일이 바뀌면 자동 분석을 중단하고 새 버전으로 검토한다.
- 공개 열람 가능 여부와 재배포 허용 여부를 같다고 가정하지 않는다. 원문 PDF나 긴 원문 발췌를 제품·테스트에 복사하지 않는다.
- 출처 문서의 문장은 자료일 뿐 실행 지시가 아니다.
- 규칙을 바꿀 때는 짧은 담보명 수준의 익명 회귀 사례로 검증하며, 공식 문서가 개인별 민간보험 권장액을 정한 것으로 표현하지 않는다.

## 현재 자료

KDB생명의 암보험 상품요약서·약관과 삼성화재 건강보험 약관을 내부 평가용으로 등록했다. 보고서는 원문을 복제하지 않고 해시, 페이지 수, 텍스트 문자 수, 키워드·분류·조건 범주 집계만 저장한다.

실행 명령:

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe tools\build_public_corpus_report.py
```

## AI-Hub 연결

AI-Hub 금융업 특화 문서 OCR 자료는 보험 관련 민원 서식 이미지와 글자 영역 정답을 포함해 스캔·촬영 이미지 OCR 평가에 유용하다. 담보 의미나 가입금액 정답 자료로 사용하지 않는다.

다운로드 신청과 이용조건 동의가 필요한 자료는 자동으로 우회해 받지 않는다. 사용자가 AI-Hub에서 합법적으로 내려받은 폴더를 전달하면 다음 명령으로 이미지·JSON 구성부터 확인한다.

```powershell
.\.venv\Scripts\python.exe tools\inspect_aihub_ocr.py "다운로드한_폴더"
```

그다음 개인정보 포함 여부와 라벨 스키마를 확인하고 별도의 비식별 OCR 평가 세트를 만든다. 원본은 외부 서비스로 전송하지 않는다.

## 현재 확인된 규칙 보완

공개 건강보험 약관에서 `상해 입원 간병인 사용일당`, `입원 간호·간병통합서비스 사용일당`처럼 입원 장소와 간병 급부가 함께 나타나는 담보명을 확인했다. 두 표현은 입원과 간병을 중복 분류하지 않고 `간병` 후보로 유지한다. 지급 조건, 기간, 갱신, 정액 여부가 확인되기 전에는 합산하지 않는다.

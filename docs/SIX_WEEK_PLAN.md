# 6주 개발계획

기능을 줄이지 않고 사용자 검수와 빠른 피드백으로 기간을 압축한다. 매주 실행 가능한 결과와 테스트 증거를 남기며 `구현 완료·테스트 전`, `테스트 완료`, `사용자 확인 완료`를 구분한다.

## 1주차 — 프로젝트 골격과 분석 기준

- 기술구조와 로컬 실행·저장 전략 확정
- 시작, 개인정보, 업로드, 분석 중, 추출 확인, 경제정보, 결과, 근거, 삭제 화면
- 계약·담보·입력·분석·근거 데이터 구조
- 업로드·저장·삭제와 가짜 데이터 종단간 흐름
- 합산 규칙, 추출값·확정값 분리

완료 기준: PDF 업로드·삭제, 가짜 데이터 전체 화면 흐름, 결과에서 계산식·원문 근거 이동, 데이터 구조와 합산 규칙의 문서·코드·테스트 일치.

## 2주차 — 실제 보험 PDF 추출 · 테스트 완료

2026-09-04: 테스트 완료. 실제 PDF 35개 담보 기본 필드·원문·수정 이력·자동 표 검산, 7쪽 로컬 OCR, 조건 근거 131건과 공통 후보 21건, 메타정보 확인 UI, 계약 중복 후보, 분석 직전 차단 관문을 검증했다. 보험회사명과 조건 의미의 사용자 예외 확인은 남아 있어 `사용자 확인 완료`는 아니다. 불확실한 값은 계산에서 제외한다.

- 텍스트 PDF와 스캔 PDF/OCR
- 보험사·상품·주계약/특약·담보·금액·보험/납입기간·갱신·지급 방식 추출
- 원문 페이지 연결, 신뢰도, 확인 필요 상태, 수정·확정 UI
- 천원/만원, 보험/납입기간, 1회/반복 지급 구분

완료 기준: 실제 PDF 주요 담보 구조화, 모든 항목의 원문 연결, 사용자 수정 가능, 불확실한 핵심값의 계산 제외. 사용자 검수는 PDF별 정답과 대조한다.

## 3주차 — 담보 표준화와 통합

- 15개 표준 담보 매핑과 원문명 보존
- 급부 유형, 정액/실손, 1회/반복, 기간·갱신 구분
- 허용된 담보만 합산하고 포함관계·차이 표시
- 쉬운 설명, 중복 가능성과 확인 필요 표시

완료 기준: 여러 보험을 위험별로 확인, 잘못된 단순 합산 방지, 쉬운 설명·주의사항, 통합 결과에서 원문·수정 이력 이동.

2026-09-07: 코드·자동 테스트 범위는 완료했다. 이름 기반 표준화, 표준군 밖/범위 확인 필요 분리, 통합 준비 상태, 원문 대조 확정 정액형만의 다문서 명목 합계, 쉬운 설명과 원문 이동을 구현했다. 실제 대상자·보험회사·상품명·담보 조건 사용자 확인과 서로 다른 보험증권의 실사용 검증은 남아 있다.

## 4주차 — 개인 자금공백 계산

- 한 사람 단위 대상자와 생애단계별 필수 입력 분기. 아동은 보호자 소득·돌봄비, 은퇴·고령기는 지속소득·돌봄비가 없으면 판단 보류
- 전체 경제정보 입력
- 중대질환 생활자금, 의료비, 사망·부채, 장기 위험 분리
- 3·6·12개월과 사용자 선택 시나리오
- 네 결과 상태, 판단 보류, 버전 재계산

완료 기준: 실제 입력으로 위험별 계산, 산식과 사용 값 표시, 정보 부족 시 판단 보류, 공적제도를 현금처럼 임의 차감하지 않음.

2026-09-08: 생애단계별 필수 입력 분기를 구현했다. 아동의 보호자 월 소득 감소·추가 돌봄비와 노년기의 사용할 월 연금·지속소득·의료돌봄 본인부담을 분리하고, 빈칸이면 분석 직전 관문과 결과 계산을 보류한다. 자동 테스트와 마이그레이션은 완료했으며 실제 사용자 금액 확인은 남아 있다.

## 5주차 — 결과·근거·보완 안내

- 보험 요약, 위험별 보장, 쉬운 설명, 자금공백, 범위·주의사항
- 계약·입력·공식 자료·가정·계산·한계·원문·수정값 근거
- 저장·열기·재분석·내보내기·전체 삭제
- 비보험 대비수단을 포함한 중립적 보완 안내

완료 기준: 모든 주요 숫자에 출처·산식, 상품 추천 없음, 결과 버전과 삭제 작동, 불확실성과 한계의 명확한 표시.

## 6주차 — 실제 보험 실사용 안정화

사용자의 모든 PDF로 전체 흐름을 반복한다. 보험사별 형식, 스캔, 여러 페이지 표, 금액 단위, 보험/납입기간, 갱신, 주계약/특약, 1회/반복, 면책·감액, 오합산, 중단 복구, 결과 PDF의 휴대전화 열람, 저장·삭제, 로그·외부 전송을 집중 검증한다. D-011 사용자 결정에 따라 모바일 전용 업로드·수정 검수는 향후 작업이다.

완료 기준: 사용자 실제 PDF 전체의 종단간 처리, 수정·안전한 통합·쉬운 설명·개인별 공백·근거·산식·가정·한계·저장·재분석·삭제가 작동하고 치명적인 개인정보 노출이나 계산 오류가 없음.

2026-10-08: 제출용 핵심 화면을 사용자 피드백에 맞춰 단순화했다. 통합 증권 요약, 4단계 모의계산, 간결한 결과, 결과 하단 보험증권 상세 링크와 보험별 입원·통원·수술 증권 표기 화면을 구현했다. 전체 자동 테스트 269개와 실제 현대해상·교보 브라우저 흐름 검수를 통과했다. 남은 제출 작업은 새 폴더 실행 재현과 제출본 개인정보·원본 제외 검사다.

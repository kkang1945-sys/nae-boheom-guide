# 내보험 사용설명서

보험증권 PDF/HWPML을 로컬에서 읽어 보장내용을 쉽게 설명하고, 사용자의 생활비·비상자금·부채·부양가족을 기준으로 생활자금 범위를 계산하는 개인용 웹앱입니다.

보험 판매, 설계사 연결, 특정 보험회사·상품 추천을 하지 않습니다. 시장 평균이나 또래 평균을 개인의 권장 가입금액으로 사용하지 않으며, 공식 제도·통계와 앱의 개인 계산을 구분합니다.

## 핵심 기능

- 여러 보험증권의 보장내용과 보장금액을 한 화면에서 확인
- PDF 텍스트 추출과 필요한 페이지만 로컬 OCR
- 추출값, 자동 검산값, 사용자 확정값 분리
- 질병별 진단비와 사망보장을 잘못 합산하지 않는 생활자금 계산
- 실손형·일당형·반복형·미확정 담보의 현금 합산 차단
- 입원·통원·수술의 보험별 증권 금액·지급조건·원문 확인
- 모든 결과에서 증권 원문, 계산식, 가정과 한계 확인
- 원본과 분석 데이터의 로컬 저장·재분석·삭제

## 실행

Windows에서 [보험앱_실행.cmd](보험앱_실행.cmd)를 더블클릭하거나 PowerShell에서 다음을 실행합니다.

```powershell
.\START_APP.ps1
```

서버가 준비되면 `http://127.0.0.1:8000`이 열립니다. 실행 창을 닫으면 앱도 종료됩니다.

새 환경에서는 Python 3.12로 가상환경과 의존성을 먼저 준비합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\START_APP.ps1
```

## 개인정보와 제출 주의

- 보험증권과 분석 데이터는 기본적으로 이 PC에만 저장됩니다.
- 생성형 AI API로 보험증권이나 개인정보를 전송하지 않습니다.
- 실제 보험 원본, `data/`, 내보내기 결과와 로컬 DB는 제출물에 포함하지 않습니다.
- 저장소의 `.gitignore`가 `*.pdf`, `*.hwp`, `data/`, `exports/`, `.env`를 제외합니다.
- 실제 지급 여부는 약관과 사고 심사에 따라 달라지며 앱 결과는 보험 가입 권유나 보험금 지급 확정이 아닙니다.

제출·시연 순서는 [docs/SUBMISSION_GUIDE.md](docs/SUBMISSION_GUIDE.md)를 참고하세요.

## 공개 시연 모드

배포 환경에서 `PUBLIC_DEMO=1`을 설정하면 개인정보 없는 합성 보험증권 두 건을 자동으로 준비합니다. 이 모드에서는 실제 보험증권 업로드와 데이터 변경 요청을 차단하고, 입력한 모의계산 값도 저장하지 않습니다. 공개 URL은 작품 체험용이며 실제 보험 분석은 로컬 실행본에서만 진행해야 합니다.
